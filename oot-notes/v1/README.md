# Ocarina of Time notes icons

Icons the Catridge app shows on its Ocarina of Time (Nintendo Switch 2) notes page, fetched at run time.
They are game art collected by Zelda Wiki (zeldawiki.wiki); each entry in `index.json` names its source.
The app downloads one `icons-<id>.zip` (the icons and `index.json`) once and keeps it; older zips stay for older app versions.
Published by `tools/oot-notes/publish-icons.mjs` in the Catridge repository.
